# Компоненты проекта

> Статус: Draft  
> Документ описывает текущий подход к созданию и организации компонентов проекта CPA.  
> Список компонентов и их интерфейсы будут обновляться по мере разработки.

## 1. Общий подход

Интерфейс проекта строится из независимых React-компонентов.

Компоненты разделяются на:

- общие UI-компоненты;
- layout-компоненты;
- секции страницы;
- функциональные компоненты.

Компонент должен иметь одну понятную ответственность и не содержать несвязанную с ним логику.

## 2. Категории компонентов

### UI-компоненты

Небольшие переиспользуемые элементы интерфейса.

Примеры:

- `Button`;
- `Typography`;
- `Input`;
- `Textarea`;
- `Container`;
- `Logo`;
- `Icon`.

UI-компоненты не должны зависеть от конкретной секции страницы.

Например, `Button` может использоваться в `Hero`, `Header` и форме.

### Layout-компоненты

Компоненты, отвечающие за общую структуру страницы.

Примеры:

- `Header`;
- `Footer`;
- `Navigation`;
- `MobileMenu`;
- `PageLayout`.

### Секции

Крупные смысловые блоки страницы.

Предварительный список:

- `Hero`;
- `Benefits`;
- `Team`;
- `JoinUs`.

Секции могут использовать общие компоненты из директории `components`.

### Функциональные компоненты

Компоненты, содержащие отдельное пользовательское поведение.

Примеры:

- `LanguageSwitcher`;
- `ContactForm`;
- `Modal`;
- `Preloader`.

Такие компоненты могут иметь локальное состояние, обработчики событий и пользовательские хуки.

## 3. Предполагаемая структура

```text
src/
├── components/
│   ├── ui/
│   │   ├── Button/
│   │   ├── Typography/
│   │   ├── Input/
│   │   └── Container/
│   ├── layout/
│   │   ├── Header/
│   │   ├── Footer/
│   │   └── MobileMenu/
│   └── common/
│       ├── LanguageSwitcher/
│       └── ContactForm/
│
└── sections/
    ├── Hero/
    ├── Benefits/
    ├── Team/
    └── JoinUs/
```
