# Project Overview

> Статус: Draft  
> Документ содержит общее описание проекта CPA и обновляется по мере развития продукта.

## 1. О проекте

CPA — это многоязычный одностраничный сайт компании, работающей в сфере performance-маркетинга и привлечения трафика.

Проект предназначен для презентации компании, её команды, преимуществ и доступных направлений сотрудничества.

Сайт должен предоставлять пользователю основную информацию о компании и возможность связаться с её представителями.

## 2. Цель проекта

Основная цель проекта — создать современный адаптивный сайт, который:

- представляет компанию и её деятельность;
- демонстрирует преимущества работы с компанией;
- знакомит пользователя с командой;
- привлекает потенциальных партнёров и сотрудников;
- позволяет пользователю быстро связаться с компанией;
- поддерживает несколько языков.

## 3. Тип проекта

Проект представляет собой одностраничный сайт, разработанный на React.

Основной контент располагается на одной странице и разделяется на смысловые секции.

Навигация выполняется с помощью прокрутки к соответствующим секциям страницы.

На текущем этапе React Router не используется.

## 4. Целевая аудитория

Основными группами пользователей являются:

- потенциальные партнёры;
- рекламодатели;
- специалисты по медиабаингу;
- кандидаты, заинтересованные в работе в компании;
- пользователи, желающие узнать больше о компании и её команде.

## 5. Основные задачи пользователя

Пользователь должен иметь возможность:

1. понять, чем занимается компания;
2. ознакомиться с преимуществами сотрудничества;
3. узнать больше о команде;
4. выбрать интересующее направление;
5. перейти к форме связи;
6. отправить контактные данные;
7. переключить язык интерфейса;
8. пользоваться сайтом на мобильном, планшетном и десктопном устройстве.

## 6. Основные секции

Предварительная структура страницы:

### Header

Содержит:

- логотип;
- навигацию;
- переключатель языка;
- кнопку открытия мобильного меню.

### Hero

Главная секция страницы.

Содержит:

- основной заголовок;
- краткое описание компании;
- основной призыв к действию;
- декоративные элементы.

### Benefits

Секция с основными преимуществами компании и сотрудничества с ней.

### Team

Секция с информацией о команде или специалистах компании.

### Join Us

Секция для потенциальных сотрудников и партнёров.

Может содержать:

- описание возможностей;
- направления сотрудничества;
- кнопку или форму связи.

### Contact Form

Форма для отправки контактной информации.

Предполагаемые поля формы будут уточнены после согласования требований.

### Footer

Содержит:

- контактную информацию;
- навигационные ссылки;
- ссылки на социальные сети;
- юридическую информацию.

Список секций может изменяться в процессе разработки.

## 7. Основная функциональность

На текущем этапе планируется следующая функциональность:

- адаптивная вёрстка;
- mobile-first подход;
- навигация по секциям;
- мобильное меню;
- переключение языка;
- локализация контента;
- форма обратной связи;
- валидация формы;
- анимации и интерактивные элементы;
- блокировка прокрутки при открытом мобильном меню или модальном окне;
- обработка состояний загрузки и ошибок.

## 8. Локализация

Проект поддерживает несколько языков.

На текущем этапе предусмотрены:

- английский — `en`;
- русский — `ru`.

Для локализации используются `i18next` и `react-i18next`.

Переключение языка уже реализуется через i18next.

В дальнейшем планируется определять язык по URL:

```text
/en
/ru
```
