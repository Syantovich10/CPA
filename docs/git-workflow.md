# Git Workflow

> Статус: Draft  
> Документ описывает правила работы с Git и GitHub в проекте CPA.

## 1. Основные ветки

В проекте используются следующие основные ветки:

- `main` — стабильная production-версия;
- `develop` — основная ветка разработки;
- `feature/*` — новые функции и компоненты;
- `fix/*` — исправления ошибок;
- `docs/*` — изменения документации;
- `refactor/*` — рефакторинг без изменения поведения.

Прямые изменения в `main` и `develop` не выполняются.

## 2. Создание новой ветки

Перед началом работы необходимо перейти в `develop` и получить актуальные изменения:

```bash
git switch develop
git pull origin develop
```
