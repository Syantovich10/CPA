# Code Style

> Статус: Draft  
> Документ описывает правила оформления и написания кода в проекте CPA.

## 1. Общие принципы

Код должен быть:

- понятным без дополнительных объяснений;
- единообразным во всём проекте;
- разбитым на небольшие логические части;
- без дублирования;
- без неиспользуемых переменных, импортов и функций;
- отформатированным с помощью Prettier;
- проверенным ESLint перед созданием Pull Request.

## 2. Форматирование

Для автоматического форматирования используется Prettier.

Основные правила:

- отступ — 2 пробела;
- одинарные кавычки;
- точка с запятой не используется;
- запятая в конце многострочных конструкций;
- максимальная длина строки определяется конфигурацией Prettier.

Пример:

```js
const navigationItems = [
  {
    label: 'Team',
    href: '#team',
  },
  {
    label: 'Benefits',
    href: '#benefits',
  },
]
```
