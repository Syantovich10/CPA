# Localization

> Статус: Draft  
> Документ описывает правила локализации проекта CPA.  
> Реализация может изменяться после окончательного согласования URL-структуры и маршрутизации.

## 1. Общая информация

Проект поддерживает несколько языков интерфейса.

На текущем этапе планируются:

- английский — `en`;
- русский — `ru`.

Основным языком проекта является английский.

Для локализации используются:

- `i18next`;
- `react-i18next`.

## 2. Определение языка

Предполагается, что язык будет определяться на основе URL.

Примеры:

```text
/en
/ru
```
