# Архитектура проекта

> Статус: Draft  
> Документ описывает текущие архитектурные решения проекта и может обновляться в процессе разработки.

## 1. Общий подход

Проект разрабатывается как одностраничное React-приложение на базе Vite.

Интерфейс разделяется на независимые компоненты и секции. Повторно используемые элементы выносятся в отдельные UI-компоненты.

Основные принципы:

- компонентный подход;
- разделение ответственности;
- переиспользование общих компонентов;
- mobile-first;
- минимизация дублирования кода;
- хранение общей логики отдельно от JSX-разметки;
- единые правила именования файлов и компонентов.

## 2. Тип приложения

Проект представляет собой одностраничный сайт.

Основные секции отображаются на одной странице:

- Header;
- Hero;
- Benefits;
- Team;
- Join Us;
- Footer.

Навигация между секциями выполняется с помощью якорных ссылок и прокрутки страницы.

React Router на текущем этапе не используется.

## 3. Структура приложения

Предполагаемая структура директории `src`:

```text
src/
├── assets/
├── components/
├── sections/
├── constants/
├── hooks/
├── locales/
├── styles/
├── utils/
├── App.jsx
└── main.jsx
```
