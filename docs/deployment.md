# Deployment

> Статус: Draft  
> Документ описывает процесс подготовки, сборки и публикации проекта CPA.  
> Информация о хостинге и автоматическом деплое будет обновлена после окончательного согласования.

## 1. Общая информация

Проект разрабатывается на React и собирается с помощью Vite.

Перед публикацией необходимо:

1. установить зависимости;
2. проверить код линтером;
3. собрать production-версию;
4. проверить результат сборки локально;
5. опубликовать содержимое production-сборки на выбранном хостинге.

## 2. Требования

Для локального запуска и сборки необходимы:

- Node.js;
- npm;
- доступ к Git-репозиторию;
- переменные окружения, если они используются.

Версии Node.js и npm должны быть одинаковыми или совместимыми у всех участников команды.

Текущую версию можно проверить командами:

```bash
node -v
npm -v
```
