# Разворачивание проекта

Документ описывает установку, локальный запуск и сборку проекта CPA.

## Требования

Перед запуском необходимо установить:

- Node.js;
- npm;
- Git.

Проверить установленные версии:

```bash
node -v
npm -v
git --version
```

## Установка проекта

Склонируйте репозиторий:

```bash
git clone <repository-url>
```

Перейдите в папку проекта:

```bash
cd CPA
```

Переключитесь на основную ветку разработки и получите актуальные изменения:

```bash
git switch develop
git pull origin develop
```

Установите зависимости:

```bash
npm install
```

## Локальный запуск

Запустите проект в режиме разработки:

```bash
npm run dev
```

После запуска Vite выведет локальный адрес проекта, обычно:

```text
http://localhost:5173
```

Если порт `5173` занят, Vite автоматически выберет другой - IP вы сможете увидеть в командной строке.

## Проверка кода

Запустите Oxlint:

```bash
npm run lint
```

Для автоматического исправления ошибок:

```bash
npm run lint:fix
```

Для форматирования файлов с помощью Prettier:

```bash
npm run format
```

Для проверки форматирования без изменения файлов:

```bash
npm run format:check
```

Для одновременной проверки кода и форматирования:

```bash
npm run check
```

Ошибки необходимо исправить перед созданием Pull Request.

## Production-сборка

Создайте production-сборку:

```bash
npm run build
```

Готовые файлы будут созданы в папке:

```text
dist/
```

Папку `dist` не нужно редактировать вручную.

Для локальной проверки production-сборки выполните:

```bash
npm run preview
```

## Основные команды

| Команда                | Назначение                        |
| ---------------------- | --------------------------------- |
| `npm install`          | Установка зависимостей            |
| `npm run dev`          | Локальный запуск проекта          |
| `npm run lint`         | Проверка кода с помощью Oxlint    |
| `npm run lint:fix`     | Автоматическое исправление ошибок |
| `npm run format`       | Форматирование с помощью Prettier |
| `npm run format:check` | Проверка форматирования           |
| `npm run check`        | Проверка кода и форматирования    |
| `npm run build`        | Создание production-сборки        |
| `npm run preview`      | Проверка production-сборки        |

## Быстрый запуск

```bash
git clone <repository-url>
cd CPA
git switch develop
npm install
npm run dev
```
