# Design System

> Статус: Draft  
> Документ описывает визуальные правила и дизайн-токены проекта CPA.  
> Значения обновляются после согласования дизайна и реализации компонентов.

## 1. Основные принципы

Интерфейс проекта разрабатывается по следующим принципам:

- mobile-first;
- единообразие визуальных элементов;
- повторное использование дизайн-токенов;
- минимизация произвольных значений;
- адаптивность;
- доступность;
- соответствие макету Figma.

Повторяющиеся цвета, размеры, отступы и радиусы не должны задаваться случайными значениями внутри отдельных компонентов.

## 2. Цветовая палитра

Цвета должны использоваться через Tailwind-токены или CSS-переменные.

### Основные цвета

| Название               | Значение | Использование              |
| ---------------------- | -------- | -------------------------- |
| `background-primary`   | TBD      | Основной фон страницы      |
| `background-secondary` | TBD      | Фон отдельных секций       |
| `text-primary`         | TBD      | Основной текст             |
| `text-secondary`       | TBD      | Второстепенный текст       |
| `accent-primary`       | TBD      | Кнопки и активные элементы |
| `accent-hover`         | TBD      | Состояние hover            |
| `border-primary`       | TBD      | Границы элементов          |
| `error`                | TBD      | Ошибки формы               |
| `success`              | TBD      | Успешные состояния         |

`TBD` означает, что значение ещё не утверждено.

Пример CSS-переменных:

```css
:root {
  --color-background-primary: #000000;
  --color-text-primary: #ffffff;
  --color-accent-primary: #7c3aed;
}
```
